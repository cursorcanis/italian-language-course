# Lexis Progression — A2 → B1

**Companion to [`a2-b1-syllabus-map.md`](a2-b1-syllabus-map.md) and
[`grammar-progression.md`](grammar-progression.md).** Twelve sets of thirty
items — **360 items** across the course — with the frequency rationale for each
set and the interlock that makes it the *right* set for that unit's grammar.

## How to read this document

### What counts as an item

An "item" is a **lexical unit**, not a word: `fare la spesa`, `andare
d'accordo` and `a un certo punto` each count as one. Counting words instead of
units would reward listing singular nouns and punish exactly the multi-word
chunks that carry B1 fluency.

Items are listed in the **citation form a learner should store**: infinitive for
verbs, singular with article for nouns where gender is not predictable,
masculine singular for adjectives.

### The selection filter

Every item had to pass all four tests. Where an item is in the set for a reason
other than raw frequency, the set's rationale says so.

1. **Frequency** — broadly within the first ~5,000 lemmas of spoken and written
   Italian, or a chunk built from items that are.
2. **Communicative payoff** — it unlocks something on the unit's can-do list.
   A tidy thematic item that unlocks nothing is cut.
3. **Interlock** — the set and the unit's grammar make each other necessary.
   See each unit's **Interlock** note.
4. **Productive vs receptive** — every item here is a **production** target.
   Recognition-only vocabulary lives in the unit's input texts and its glossary,
   is not counted in the thirty, and is not tested at the checkpoint.

### Volume, and why it is thirty

Thirty productive items per unit × twelve units = 360, on top of an assumed
solid A2 base of roughly 1,200–1,500. That lands a learner near 1,800 productive
items at exit, which is a defensible B1 productive vocabulary.

Thirty over five 90-minute lessons is six new items per lesson — low enough that
each can be met, used and recycled rather than merely listed. Under **cognitive
load**, a forty-item set would look more generous on paper and deliver less.

### What is binding on whom

- **Lesson Designer (ITA-5):** set A is introduced in `L1`, set B in `L3`. Every
  item must be *used*, not just glossed.
- **Italian Content Editor:** these lists are the vetting queue. Flag anything
  regionally marked, dated, register-wrong, or wrong in gender or form.
- **Assessment (ITA-4):** checkpoints test a unit's own set plus recycled items
  from the sets named in that unit's **Recycled from earlier sets** note.

## The false-friend thread

Referenced from [`a2-b1-syllabus-map.md`](a2-b1-syllabus-map.md). English is the
learner L1, so the false-friend load is a *specific, predictable* one. These
twelve items are handled as a **single running strand**, one per unit, rather
than scattered — a recurring two-minute slot in `L3` that learners come to
expect. They sit **outside** the thirty and are tested cumulatively at both
milestones.

| Unit | Item | Actually means | English word it is not |
| --- | --- | --- | --- |
| 1 | `i parenti` | relatives | *parents* → `i genitori` |
| 2 | `la fattoria` | farm | *factory* → `la fabbrica` |
| 3 | `la libreria` | bookshop | *library* → `la biblioteca` |
| 4 | `morbido` | soft | *morbid* → `morboso` |
| 5 | `sensibile` | sensitive | *sensible* → `ragionevole` |
| 6 | `i preservativi` | condoms | *preservatives* → `i conservanti` (the taught item; see Set 6) |
| 7 | `la patente` | driving licence | *patent* → `il brevetto` |
| 8 | `l'ambulatorio` | doctor's surgery, clinic | *ambulance* → `l'ambulanza` |
| 9 | `pretendere` | to demand, to expect as one's due | *to pretend* → `fingere` |
| 10 | `attuale` | current, present-day | *actual* → `effettivo`, `vero e proprio` |
| 11 | `eventualmente` | if need be, should it arise | *eventually* → `alla fine` |
| 12 | `attualmente` | currently | *actually* → `in realtà`, `anzi` |

`attuale` (U10) and `attualmente` (U12) are deliberately paired two units apart:
the adjective first, then the adverb, so the second is a confirmation rather
than a fresh trap.

## Unit 1 — Routine, carattere, rapporti

**Set 1** · 30 items · Unit theme: *me, my week, my people* · Level A2

**Why these thirty.** Routine and people are the two things a learner at A2 can
already half-talk about and will be asked about within a minute of meeting
anyone. The set is weighted toward **reflexive verbs** because they are both the
unit's grammar and the natural encoding of a daily routine in Italian — an
anglophone who has not got them says *mi alzo* as *io levo* or avoids the topic.
Character adjectives are chosen for the ones that let a learner say something
*evaluative* rather than merely factual (`in gamba`, `permaloso`), because
"my sister is nice" is A1 and the goal here is A2 with texture.

### A. Reflexive routine verbs (11)

| Italian | English | Note |
| --- | --- | --- |
| `svegliarsi` | to wake up | |
| `alzarsi` | to get up | |
| `farsi la doccia` | to have a shower | Reflexive **with** a direct object; the participle still agrees with the subject (`mi sono fatta la doccia`). Anticipates U6. |
| `vestirsi` | to get dressed | |
| `prepararsi` | to get ready | |
| `sbrigarsi` | to hurry up | High-frequency in the imperative; seeds U7. |
| `occuparsi di` | to deal with, look after | |
| `riposarsi` | to rest | |
| `rilassarsi` | to relax | |
| `addormentarsi` | to fall asleep | Contrast with `dormire`: inceptive vs durative. |
| `trovarsi (bene / male)` | to be comfortable, to be settled | |

### B. People and relationships (8)

| --- | --- | --- |

| `i parenti` | relatives | False-friend strand, U1. |

### C. Character adjectives and how you get on (11)

| Italian | English | Note |
| --- | --- | --- |
| `socievole` | sociable | |
| `riservato` | reserved | |
| `testardo` | stubborn | |
| `permaloso` | touchy, easily offended | Very high spoken frequency; no neat English equivalent. |
| `affidabile` | reliable | |
| `disponibile` | helpful, willing to help | Also "available" — both senses are used. |
| `in gamba` | capable, on the ball | Fixed chunk. |
| `andare d'accordo (con)` | to get on (with) | |
| `litigare` | to argue, to fall out | |

**Plus, outside the thirty:** the five-chunk receptive `piacere` set — `mi

analysed at U8. See [`grammar-progression.md`
§Receptive seeding](grammar-progression.md#receptive-seeding).

**Interlock.** The reflexive paradigm is unteachable without routine verbs, and
routine is untellable in Italian without the reflexive. `vedersi` and `sentirsi`
in set C carry the reciprocal use, which is the same morphology doing a
different job — so the grammar point gets two distinct functions from one set.

**Recycled from earlier sets.** None — entry unit.

## Unit 2 — Eventi e svolte

**Set 2** · 30 items · Unit theme: *my last year* · Level A2

**Why these thirty.** The passato prossimo is useless without something worth
narrating and something to anchor it in time. Subgroup A exists so that
learners stop producing undated strings of events. Subgroup B is deliberately
loaded with **`essere`-auxiliary and reflexive verbs** (`trasferirsi`,
`iscriversi`, `laurearsi`, `licenziarsi`, `separarsi`) — the auxiliary choice is
the single biggest anglophone error at this point, and the lexis set is chosen
so learners cannot avoid practising it. Subgroup C gives the evaluative language
that turns a list of events into a story someone wants to hear.

### A. Time anchors (10)

| Italian | English | Note |
| --- | --- | --- |
| `l'anno scorso` | last year | |
| `il mese scorso` | last month | |
| `due anni fa` | two years ago | Pattern `[quantity] + fa`. |
| `da allora` | since then | |
| `all'inizio` | at first | |
| `alla fine` | in the end | |
| `di recente` | recently | |
| `finora` | so far | |
| `già` | already | Position with the auxiliary is the point. |
| `appena` | just | Narrative *as soon as* use is seeded for U5. |

`non ancora` (*not yet*) is taught with `già` as its negative counterpart and
counted with it.

### B. Life-event verbs and nouns (12)

| Italian | English | Note |
| --- | --- | --- |
| `trasferirsi` | to move house, to relocate | Feeds U3 directly. |
| `iscriversi (a)` | to enrol, to sign up | Irregular participle `iscritto`. |
| `laurearsi` | to graduate | |
| `la laurea` | degree | |
| `licenziarsi` | to resign | Contrast `essere licenziato` = to be fired. A real-consequences distinction. |
| `assumere` | to hire, to take on | Irregular participle `assunto`. Feeds U10. |
| `separarsi` | to separate, to split up | |
| `il trasloco` | the house move | |
| `il colloquio` | interview | Feeds U10. |
| `il tirocinio` | internship, placement | |
| `la svolta` | turning point | |
| `la fattoria` | farm | False-friend strand, U2. |

### C. Outcome and evaluation (8)

| Italian | English | Note |
| --- | --- | --- |
| `andare bene` / `andare male` | to go well / badly | |
| `riuscire (a)` | to manage to | `essere` auxiliary — high-value practice. |
| `rendersi conto (di)` | to realise | |
| `valere la pena` | to be worth it | |
| `pentirsi (di)` | to regret | |
| `soddisfatto` | satisfied, pleased | |
| `deluso` | disappointed | |
| `inaspettato` | unexpected | Seeds U5. |

**Interlock.** Five of the twelve life-event verbs take `essere` and are
reflexive, so the passato prossimo's hardest feature — auxiliary choice plus
participle agreement — is forced by the vocabulary rather than drilled in the
abstract. Choosing a theme like *food* here would have let learners narrate
entirely in `avere` and never meet the problem.

**Recycled from earlier sets.** Set 1 reflexives, now in the past
(`mi sono trasferito`). Set 1 people, as the cast of the year's events.

## Unit 3 — Casa, palazzo, quartiere

**Set 3** · 30 items · Unit theme: *home, building, neighbourhood* · Level A2+

**Why these thirty.** This is the most immediately cashable set in the first
half of the course: a learner living in or visiting Italy needs it within days.
Subgroup A is specifically **Italian** domestic architecture — `pianerottolo`,
`portone`, `citofono`, `cortile` have no clean English equivalent and describe
things an anglophone will physically encounter and be unable to name. Subgroup
B is the rental transaction, chosen over "furniture" because furniture is
picturable and therefore survivable without words, while `spese condominiali`
is not. Subgroup C supplies the adjectives that comparatives operate on.

### A. The building and its parts (10)

| Italian | English | Note |
| --- | --- | --- |
| `il palazzo` | apartment block | Not "palace" in ordinary use. |
| `il portone` | the main street door | |
| `il citofono` | entryphone | |
| `il pianerottolo` | landing | |
| `l'ascensore` | lift | Masculine. |
| `il cortile` | courtyard | |
| `il balcone` | balcony | |
| `la cantina` | cellar, storage room | Not "canteen". |
| `il piano terra` / `il primo piano` | ground floor / first floor | Italian and British numbering agree; American does not. |
| `il riscaldamento` | heating | `autonomo` vs `centralizzato` matters in rentals. |

### B. Renting and running costs (8)

| Italian | English | Note |
| --- | --- | --- |
| `l'affitto` | rent | |
| `affittare` | to rent | Ambiguous in direction; `prendere in affitto` disambiguates. |
| `il contratto di locazione` | tenancy agreement | |
| `la cauzione` | deposit (refundable, on a rental) | `il deposito cauzionale` is the term in the contract. Not `la caparra` / `l'acconto` (U11), which are advances on a price. |
| `le spese condominiali` | service charges | |
| `le bollette` | utility bills | |
| `l'agenzia immobiliare` | estate agency | |
| `arredato` / `non arredato` | furnished / unfurnished | |

### C. Describing and comparing places (12)

| Italian | English | Note |
| --- | --- | --- |
| `luminoso` | bright, light-filled | The single most common adjective in Italian property ads. |
| `spazioso` | spacious | |
| `accogliente` | welcoming, cosy | |
| `rumoroso` | noisy | |
| `tranquillo` | quiet, peaceful | |
| `ben collegato` | well connected (for transport) | Feeds U7. |
| `in centro` | central, in the centre | |
| `periferico` | on the outskirts | |
| `il quartiere` | neighbourhood | |
| `i servizi` | local amenities | |
| `comodo (a)` | handy (for) | |
| `la libreria` | bookshop | False-friend strand, U3. Also a neighbourhood amenity — earns its place twice. |

### D. Seeded outside the thirty

`vorrei` and `potrebbe` enter here as **recognition-only chunks** in the
estate-agency and viewing dialogues — the start of the condizionale-di-cortesia
seed that pays off at U11. See [`grammar-progression.md`
§Receptive seeding](grammar-progression.md#receptive-seeding).

**Interlock.** Relative clauses need referents worth qualifying, and a building
full of unfamiliar parts supplies them (`il vicino che abita al piano di
sopra`, `il cortile in cui giocano i bambini`). Comparatives need two comparable
things with shared attributes — two flats, two neighbourhoods — and subgroup C
is built to be the attribute list. `ci` locativo needs a place already named:
`Ci abito da due anni`.

**Recycled from earlier sets.** Set 2 life events (`mi sono trasferito`,
`il trasloco`). Set 1 character adjectives, extended from people to places and
to neighbours.

## Unit 4 — Infanzia, abitudine, cambiamento

**Set 4** · 30 items · Unit theme: *childhood and change* · Level A2+

**Why these thirty.** The imperfetto needs a topic where *habitual* and
*descriptive* past are the only sensible readings; childhood supplies it without
the learner having to choose between tenses yet — the contrast is U5's job.
Subgroup A is concrete and school-shaped because those are the memories
everyone has and they are culturally specific enough to be worth teaching
(`le elementari`, `la ricreazione`, `la merenda`). Subgroup B is small and
functional: the frequency adverbs the imperfetto collocates with. Subgroup C is
the emotional register that makes the topic speakable at length.

### A. Childhood and its places (12)

| Italian | English | Note |
| --- | --- | --- |
| `l'infanzia` | childhood | |
| `da piccolo` / `da bambino` | as a child | Fixed chunk with the imperfetto. |
| `crescere` | to grow up | |
| `il compagno di classe` | classmate | |
| `la maestra` | primary-school teacher | Distinct from `il professore` (secondary). |
| `le elementari` | primary school | |
| `le medie` | middle school | No English equivalent stage. |
| `la ricreazione` | break time | |
| `il quaderno` | exercise book | |
| `la merenda` | afternoon snack | Culturally loaded; feeds U6. |
| `il campetto` | the local pitch | |
| `morbido` | soft | False-friend strand, U4. |

### B. Habit and frequency (8)

| Italian | English | Note |
| --- | --- | --- |
| `di solito` | usually | |
| `ogni tanto` | now and then | |
| `raramente` | rarely | |
| `una volta alla settimana` | once a week | Productive pattern. |
| `per lo più` | mostly, for the most part | |
| `l'abitudine` | habit | |
| `abituarsi (a)` | to get used to | Process. |
| `essere abituato (a)` | to be used to | State. The two are confused constantly. |

### C. Change, loss and nostalgia (10)

| Italian | English | Note |
| --- | --- | --- |
| `cambiare` | to change | Takes `avere` or `essere` depending on transitivity. |
| `trasformarsi` | to turn into, to change completely | `trasformarsi in`. *To be transformed* by someone is `essere trasformato`. |
| `una volta` | back then, in the past | Also "once"; the temporal-setting use is the target. |
| `ai miei tempi` | in my day | |
| `non… più` | no longer | |
| `mancare` | to be missing, to be missed | Second appearance of the `piacere` pattern, still unanalysed. |
| `la nostalgia` | nostalgia, longing | Broader and less literary than the English. |
| `rimpiangere` | to miss, to regret the loss of | |
| `sparire` | to disappear | |
| `restare` / `rimanere` | to stay, to remain | |

**Interlock.** Subgroup B's frequency adverbs are the imperfetto's natural
collocates — you cannot teach `di solito` convincingly in the passato prossimo.
Subgroup C's `una volta` and `ai miei tempi` are exactly the frames that trigger
`si` impersonale in real speech (`una volta si usciva di più`), which is this
unit's secondary point. And `non… più` is the hinge the whole *then vs now*
comparison turns on.

**Recycled from earlier sets.** Set 3 place adjectives, now describing
remembered places. Set 1 reflexives, now habitual (`mi svegliavo`). Set 1
character adjectives, describing people as they were.

## Unit 5 — Imprevisti e reazioni

**Set 5** · 30 items · Unit theme: *telling what happened* · Level B1 lower

**Why these thirty.** The passato prossimo / imperfetto contrast cannot be
practised on neutral content: it needs events that interrupt backgrounds.
Subgroup B is therefore a list of **interruptions** — things that happen *to*
you at a point in time, against a scene that was already running. Subgroup A is
the highest-payoff subgroup in the first half of the course: narrative
signposts are what separate a B1 speaker from an A2 speaker with the same
grammar, and they are cheap to learn and instantly reusable. Subgroup C
supplies the reaction verbs, all reflexive, so the recycling is built in.

### A. Narrative signposts and connectives (10)

| Italian | English | Note |
| --- | --- | --- |
| `allora` | so, right then | Discourse use, not "at that time". |
| `a un certo punto` | at a certain point | The single most useful narrative chunk at B1. |
| `all'improvviso` | suddenly | |
| `mentre` | while | Selects the imperfetto — the grammar point in one word. |
| `appena` | as soon as | Second sense; `già`-sense taught U2. |
| `così` | so, and so | Consequence. |
| `però` | but, though | Can be sentence-final in speech. |
| `insomma` | in short, anyway | |
| `comunque` | anyway, in any case | |
| `il fatto è che` | the thing is | |

### B. Things that go wrong (12)

| Italian | English | Note |
| --- | --- | --- |
| `l'imprevisto` | unforeseen event, hitch | |
| `il guasto` | breakdown, fault | |
| `rompersi` | to break | |
| `perdere` | to miss, to lose | `perdere il treno`, `perdere le chiavi`. |
| `dimenticarsi (di)` | to forget | |
| `sbagliare` | to get wrong | `sbagliare strada`, `sbagliare numero`. |
| `cadere` | to fall | `essere` auxiliary. |
| `rimanere bloccato` | to get stuck | |
| `lo sciopero` | strike | Practically necessary in Italy. |
| `il ritardo` | delay | Feeds U7. |
| `il furto` | theft | |
| `sensibile` | sensitive | False-friend strand, U5. |

### C. Reactions and outcomes (8)

| Italian | English | Note |
| --- | --- | --- |
| `spaventarsi` | to get frightened | |
| `arrabbiarsi` | to get angry | |
| `accorgersi (di)` | to notice, to realise | Irregular participle `accorto`. |
| `preoccuparsi` | to worry | |
| `risolvere` | to solve, to sort out | |
| `cavarsela` | to manage, to get by | Pronominal verb; taught as a chunk, formally unpacked at U11. |
| `per fortuna` | luckily | |
| `meno male` | just as well, thank goodness | |

**Interlock.** `mentre` selects the imperfetto and `a un certo punto` selects
the passato prossimo. The two most frequent items in subgroup A *are* the two
sides of the unit's grammar point, so every time a learner reaches for a
signpost they are choosing a tense. Subgroup C's reflexives recycle U1 inside a
narrative frame, which is also where `stare + gerundio` becomes necessary:
`stavo uscendo quando mi sono accorto che…`.

**Recycled from earlier sets.** Set 2 time anchors, placing the anecdote before
the connectives take over. Set 1 reflexives, in narrative. Set 2 `inaspettato`,
now with a story attached.

## Unit 6 — Mercato, quantità, cucina

**Set 6** · 30 items · Unit theme: *market, shopping, cooking* · Level B1 lower

**Why these thirty.** Direct pronouns and partitive `ne` need referents that are
**countable, repeatedly mentioned, and tedious to keep naming** — which is
exactly what a market transaction produces. Subgroup B is small (7) because
quantity expressions are a closed, highly patterned set and do not need more
room; the space goes to subgroup C, where process verbs let learners sequence
an extended monologue. The set deliberately avoids listing produce: food nouns
are the most learnable vocabulary in any language and do not need syllabus time.

### A. Market and transaction (11)

| Italian | English | Note |
| --- | --- | --- |
| `il banco` | market stall, counter | |
| `il fruttivendolo` | greengrocer | |
| `la macelleria` | butcher's | |
| `la panetteria` | baker's | |
| `fare la spesa` | to do the food shopping | Distinct from `fare spese` / `fare shopping` = to go shopping. |
| `assaggiare` | to taste, to try | |
| `maturo` | ripe | |
| `di stagione` | in season | |
| `lo sconto` | discount | |
| `il resto` | the change | |
| `i conservanti` | preservatives | `senza conservanti` is on every Italian food label. The word it is not — `i preservativi` = *condoms* — stays in the false-friend strand as a recognition item rather than a market-stall production target. |

### B. Quantities and containers (7)

| Italian | English | Note |
| --- | --- | --- |
| `un etto` | 100 grams | The default market unit; no English equivalent. |
| `mezzo chilo` | half a kilo | |
| `un pacco (di)` | a packet (of) | |
| `una confezione` | a pack | |
| `un barattolo` | a jar, a tin | |
| `una fetta` | a slice | |
| `un pizzico` | a pinch | |

### C. Cooking process and qualities (12)

| Italian | English | Note |
| --- | --- | --- |
| `mescolare` | to stir, to mix | |
| `tagliare` | to cut | |
| `sbucciare` | to peel | |
| `bollire` | to boil | |
| `soffriggere` | to fry gently | Irregular participle `soffritto`. |
| `scolare` | to drain | |
| `condire` | to dress, to season | |
| `aggiungere` | to add | Irregular participle `aggiunto`. |
| `la pentola` | pot, saucepan | |
| `la padella` | frying pan | |
| `saporito` | tasty, well-flavoured | |
| `insipido` | bland, underseasoned | |

**Interlock.** A recipe is the only everyday text type where a learner must
refer back to the same object six times in a row — so `lo`, `la`, `li`, `le` and
`ne` are not a grammar exercise here, they are the only natural way to speak.
Participle agreement (`li ho comprati`) gets its motivation from subgroup B,
because quantities force plural referents. And a recipe is also the input side
of U7's imperative: learners hear `mescolate`, `aggiungete` in `L1` a full unit
before producing imperatives.

**Recycled from earlier sets.** Set 2 passato prossimo verbs, now with
preceding-pronoun agreement. Set 3 comparatives and place adjectives, used to
choose between products. Set 4 `la merenda`, extended. Set 1 present tense, in
its fullest transactional use.

> **Milestone 1** sits after this unit and tests Sets 1–6 cumulatively.

## Unit 7 — Trasporti, strada, sportello

**Set 7** · 30 items · Unit theme: *transport, streets, offices* · Level B1 lower

**Why these thirty.** This is the highest-consequence set in the course: not
knowing `obliterare` costs a learner a €50 fine, and not knowing `la marca da
bollo` costs them a morning. Subgroup C is the largest (11) because Italian
bureaucratic vocabulary is genuinely opaque, unavoidable for anyone living in
Italy, and taught almost nowhere. The set is chosen for **payoff over
frequency** and that trade is deliberate: `il numeretto` is not a high-frequency
lemma, but the day a learner needs it, nothing else will do.

### A. Transport and tickets (9)

| Italian | English | Note |
| --- | --- | --- |
| `il biglietto` | ticket | |
| `obliterare` / `timbrare` | to validate (a ticket) | `timbrare` is the everyday word; `obliterare` is what the sign says. |

## Unit 9 — Favori, regali, rapporti

**Set 9** · 30 items · Unit theme: *asking and owing* · Level B1

**Why these thirty.** Combined pronouns need a theme where **two participants
and a transferred object** are in every single sentence — favours, lending and
gift-giving are that theme and very little else is. `me lo presti?`,
`gliel'ho restituito`, `te lo dico dopo` are not exercises here, they are the
only economical way to say the thing. Subgroup C is included because relationship
repair is the most under-taught high-payoff area at B1: learners can transact

## Unit 10 — Lavoro, contratti, obiettivi

**Set 10** · 30 items · Unit theme: *work and what's next* · Level B1

**Why these thirty.** Two jobs at once: the futuro needs a theme where talking
about non-present time is natural rather than contrived, and the course needs to
deliver the semi-formal register that B1 claims. Subgroup A is weighted toward
**contract and conditions** vocabulary because that is where the money and the
misunderstandings are, and because job adverts are the single most `si`

## Unit 11 — Prenotazioni, ospitalità, reclami

**Set 11** · 30 items · Unit theme: *travel, hospitality, requests* · Level B1

**Why these thirty.** The condizionale earns its slot on **communicative
payoff** — polite requests are usable the day they are learnt — and subgroup B
is the set that makes that concrete. It is deliberately large (11) and made
almost entirely of **chunks rather than single words**, because politeness in
Italian is formulaic and a learner who has the formulae sounds far better than
one who has the morphology. Subgroup C is the complaint vocabulary, which is
where the trapassato finally has a reason to exist.

## Unit 12 — Media, opinione, dibattito

**Set 12** · 30 items · Unit theme: *news, debate, persuasion* · Level B1

**Why these thirty.** Subgroup A is the largest (11) and is essentially a list
of **congiuntivo triggers** — that is not a coincidence, it is the design. A
first look at the congiuntivo is only teachable if the learner has a closed,
memorable set of verbs that govern it, so the lexis set *is* the grammar
inventory. Subgroup B is chosen for media literacy as much as language: `la
fonte`, `attendibile`, `la bufala` are what let a learner talk about news
critically rather than just report it. Subgroup C completes the connective
strand begun at U5, moving from narrative to argument.

`però` and `infatti` / `anzi` pairs give the register and polarity distinctions
that make a B1 argument sound structured rather than listed.

## How the sets interlock across the course

Three strands run the full length of the course rather than sitting inside one
unit. Each is listed here because it is easy to lose when units are built one at
a time.

### 1. The `piacere` strand

`mi piace` (U1, chunk) → `mancare` (U4, nostalgia, still a chunk) →
**analysed as a paradigm** (U8) → `mi sembra che` as a congiuntivo trigger
(U12). One pattern, four appearances, seven units between planting and
explanation. This is the course's flagship **input-before-output** case and the
model for the congiuntivo seed.

### 2. The connective strand

Narrative signposts (U5, 10 items) → carried in the symptom history (U8) →
holding a repair account together (U9) → extended to argumentative connectives
(U12, 10 items). Twenty items total, and the U12 subgroup is explicitly taught
*against* the U5 one — `però` → `tuttavia`, `così` → `quindi` — so the learner
gains a register axis rather than a second unrelated list.

### 3. The false-friend strand

Twelve items, one per unit, outside the thirty. Listed in full
[above](#the-false-friend-thread). Cumulative, and tested at both milestones.

### Deliberate re-entries

Items that appear in one set and are re-used, in a new sense or a new register,
in a later one. These are **not** double-counted in the 360.

| Item | First set | Re-entry | What changes |
| --- | --- | --- | --- |
| `sentirsi` | 1 (reciprocal, *to be in touch*) | 8 (*to feel*) | Sense |
| `mancare` | 1 (chunk) → 4 (nostalgia) | 8 (paradigm) | Analysis |
| `il vicino` | 1 (people) | 3 (the building) | Theme |
| `il colloquio` | 2 (life events) | 10 (recruitment) | Register |

| `però` | 5 | 12 (`tuttavia`) | Register |
| `attuale` | 10 | 12 (`attualmente`) | Word class |
