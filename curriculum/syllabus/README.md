# Syllabus

The A2→B1 syllabus map lives here: the full 12-unit grid with, for each unit,
its theme, can-do goals, grammar focus, lexis set, and the points where earlier
structures are recycled.

Expected files:

- `a2-b1-syllabus-map.md` — the grid, readable in one sitting.
- `grammar-progression.md` — every structure with its three appearances
  (introduced → recycled → free production).
- `lexis-progression.md` — the ~30-item set per unit and how sets interlock.
