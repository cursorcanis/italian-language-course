## What this is

One instrument, instantiated twelve times. It sits in every unit's **L5**
alongside the production task (map §The lesson-slot convention), takes about ten
minutes, and answers one question: **did this unit land?**

Twelve separately-designed checkpoints would drift, and a learner's score in
Unit 9 would not be comparable to their score in Unit 3. This template fixes the
shape, the mark allocation, the marking rules and the pass criterion once. The
[§Per-unit parameters](#per-unit-parameters) table supplies the twelve sets of
content parameters — which structures, which lexis, which text type — and
nothing else varies.

### Task type, duration, what it measures, pass criterion

| | |
| --- | --- |
| **Task type** | Four-part mixed check: short receptive text or script, contextual grammar items, lexis-in-context items, one short productive turn. |
| **Duration** | **10 minutes** of learner time: 3 + 3 + 2 + 2. Marking takes a partner about 5 minutes, or the learner about 3 for the self-markable parts. |
| **What it measures** | (1) the unit's can-do goals; (2) the unit's **main** grammar structure, in production; (3) **at least one structure recycled from an earlier unit**, as required by [`grammar-progression.md` §What this hands to ITA-4](../curriculum/syllabus/grammar-progression.md#what-this-hands-to-ita-4); (4) the unit's lexis set, in use rather than in translation. |
| **Pass criterion** | **≥ 18 / 25 overall**, **and** productive TA ≥ 3, **and** productive TS ≥ 3, **and** ≥ 1 / 2 on the recycled-structure items. All four conditions. See [§Pass criterion](#pass-criterion-and-what-a-fail-does). |

### What it deliberately does not measure

- **The unit's production task.** That is separately assessed at L5 against its
  own success criterion, already published per unit in the syllabus map. The
  checkpoint is the short, comparable, repeatable instrument; the production
  task is the long, unit-specific one. Duplicating one inside the other would
  cost lesson time and buy nothing.
- **Pronunciation and the culture note.** Both are taught (L3, L4) and neither is
  checked here. Pronunciation is marked where it carries meaning, inside FD on
  spoken productive turns; the culture note is not a testable construct at ten
  minutes and testing it would turn it into trivia.
- **The congiuntivo before Unit 12.** It is seeded receptively from U5
  ([`grammar-progression.md` §Receptive seeding](../curriculum/syllabus/grammar-progression.md#receptive-seeding))
  and is **excluded from every checkpoint before U12**. A seeded chunk that gets
  tested stops being seeding and becomes an untaught demand.

## The four parts

### Part A — Receptive (3 minutes, 4 marks)

| | |
| --- | --- |
| **Task type** | One short text (60–90 words) **or** one script-read recording (40–60 seconds), whichever matches the unit's dominant text type — the parameter table names which. |
| **Items** | 4, worth 1 each: **1 gist** + **2 detail** + **1 that cannot be answered without parsing the unit's main structure**. |
| **Construct rule** | The text uses only lexis from this unit's set and earlier sets. An item that requires a word the learner has not met tests vocabulary breadth, not comprehension, and is rejected. |
| **The fourth item** | This is the item that makes Part A worth three minutes. It must be constructed so that a learner who ignores the unit's main structure gets it wrong — e.g. at U6, an item whose answer depends on whether `ne ho presi due` or `li ho presi` was said; at U5, an item that turns on which of two events was the background. Keyword matching must not reach the key. |
| **Marking** | Objective key. Spelling and accents not marked. Learner-markable. |

### Part B — Grammar in context (3 minutes, 6 marks)

| | |
| --- | --- |
| **Task type** | A single short connected text (70–90 words) with **6 gaps**, one to three words each, **no options supplied**. Not six isolated sentences. |
| **Split** | **4 gaps on this unit's main structure** · **2 gaps on the named recycled structure(s)** from the parameter table. |
| **Why cloze** | The same reason as in the placement check: a gap inside co-text requires the learner to read to choose, and makes avoidance impossible. Multiple choice would let a learner recognise a form they could not produce, three days after being taught it — the least informative possible result. |
| **Marking** | 1 mark each, all-or-nothing. Each gap carries a stated alternatives list. Where agreement is part of the target (participle agreement at U6, `glie-` fusion at U9), agreement is part of the key and is stated as such. Spelling and accents not marked unless the accent distinguishes the form. |
| **Recycled items** | These two marks are the spiral made checkable. If a unit's checkpoint has no recycled items, the unit's `L4` has no external check on whether it recycled anything, and the spiral becomes an intention. |

### Part C — Lexis in context (2 minutes, 5 marks)

| | |
| --- | --- |
| **Task type** | 5 items, 1 mark each, drawn from **two different subgroups** of the unit's lexis set (parameter table names which). Two formats only, so learners are not learning a new mechanic every unit: **(a) collocation completion** — a short phrase with the collocate missing; **(b) odd-one-out within a stated semantic field**, where the learner also writes why in one English word. |
| **What it measures** | Whether items are available *in use*. Not translation: an L1↔L2 translation item measures recall of a pair, which is the weakest thing worth knowing about a lexical item, and it rewards exactly the flashcard habit the lexis progression's selection filter is designed to move learners past. |
| **Coverage rule** | Across a unit's checkpoint, the 5 items sample at least 2 of the 3 subgroups, and at least 1 item must be a **chunk** rather than a single word. |
| **False friends** | Where the unit carries one from [§The false-friend thread](../curriculum/syllabus/lexis-progression.md#the-false-friend-thread), **one** of the five items targets it, in a context where the English-interference answer is plainly wrong in Italian. One per checkpoint maximum: more than that and the checkpoint becomes a trap collection. |
| **Marking** | Objective key with alternatives. Learner-markable. |

### Part D — Productive turn (2 minutes, 10 marks)

| | |
| --- | --- |
| **Task type** | One short turn: **spoken, 45–60 seconds recorded**, or **written, 40–60 words**. The parameter table names which, chosen to match the unit's can-do goals — a unit whose goals are transactional gets a spoken turn. |
| **Prompt spec** | A single situation with **two or three required elements**, stated in English, engineered so the unit's main structure is the natural way to do it. The prompt never names the structure. A prompt that says "use the conditional" tests instruction-following. |
| **Elicitation floor** | Stated per unit in the parameter table — the minimum number of attempts at the main structure a passing answer needs. Below the floor, TS cannot exceed 2 ([`rubrics.md` §TS](rubrics.md#scale-ts--range-and-control-of-the-target-structure-05)). |
| **Scales** | **TA ×1** (0–5) + **TS ×1** (0–5) = 10 marks. TS target is the unit's main structure. **GA is not used** — 50 words is too short a sample to score general accuracy reliably, and scoring it anyway would mostly measure which errors happened to fit in the window. **CC is not used** — below the threshold in [`rubrics.md`](rubrics.md#scale-cc--coherence-and-cohesion-05). |
| **Self-marking** | Learner scores **TA only**, against the required elements as a checklist. **TS goes to a partner.** A learner cannot reliably score their own control of a structure they learned this week — and the direction of the error is always optimistic. |
| **Solo without a partner** | Record the turn, score TA, and leave TS blank. The checkpoint result is then **provisional** and the learner is told what it cannot tell them: whether the form was right. Provisional results do not gate anything (nothing here gates), but two consecutive provisional results should trigger finding a marker — see [§Open](#open-and-who-owns-it). |

## Mark allocation

| Part | Marks | Nature | Self-markable |
| --- | --- | --- | --- |
| A — Receptive | 4 | objective | yes |
| B — Grammar in context | 6 | objective (4 main + 2 recycled) | yes |
| C — Lexis in context | 5 | objective | yes |
| D — Productive turn | 10 | TA 5 + TS 5 | TA only |
| **Total** | **25** | | 15 of 25 |

Productive is 10 of 25 — 40% on a ten-minute instrument. That is as far as
**washback** can be pushed at this length: a checkpoint weighted more heavily
toward production would need more than two minutes of speech to be reliable, and
the checkpoint would stop being a checkpoint.

## Pass criterion, and what a fail does

### Pass

All four conditions:

1. **≥ 18 / 25** overall (72%);
2. **productive TA ≥ 3** — the standing floor across all four instruments;
3. **productive TS ≥ 3** — the unit's main structure is controlled well enough to use;
4. **≥ 1 / 2** on Part B's recycled items.

Condition 4 is the one that looks small and is not. Without it, a learner can
pass every checkpoint in the course while losing every structure a week after
its unit ends, and the course's central claim — that it spirals — would have no
instrument behind it.

### A fail does not block progression

This is a design decision, and it is the opposite of what an exam-shaped course
would do. **A failed checkpoint does not stop the learner starting the next
unit.** Three reasons:

- **Spiral progression.** Every structure has two further encounters already
  located by unit and lesson. Holding a learner at Unit 6 until they pass Unit
  6's checkpoint means re-teaching a structure in isolation that the course was
  about to re-teach inside a new theme, which is the weaker intervention.
- **Cognitive load.** A structure that did not land in week one often lands at
  its second encounter without any extra teaching. Repeating the unit spends the
  learner's time to buy what spacing gives free.
- **Self-study reality** (format brief §2). A gate a solo learner can simply
  ignore is not a gate; it is a discouragement. A carry-forward list is
  something they can act on.

### What a fail does instead — the carry-forward list

A failed checkpoint writes a **named entry** on the learner's carry-forward
list: the structure, the unit it came from, and the **later `L4` where it is
already scheduled to return**, taken from the
[per-unit `L4` contract](../curriculum/syllabus/grammar-progression.md#per-unit-l4-contract).
The entry is closed when that `L4` is done *and* the structure appears correctly
in a later checkpoint or milestone.

| Failed at | Carry-forward entry reads | Closes at |
| --- | --- | --- |
| U2 (passato prossimo) | "PP auxiliary + agreement — returns U6 L4" | U6 checkpoint Part B recycled items |
| U6 (direct pronouns / `ne`) | "direct pronouns + `ne` — return U8 L4 and U10 L4" | U8 / U10 checkpoints, Milestone 1 |
| U9 (combinati) | "pronomi combinati — return U11 L4" | U11 checkpoint, Milestone 2 |

Every structure in the course has such a return point except the two named in
[`grammar-progression.md` §Spacing audit](../curriculum/syllabus/grammar-progression.md#where-spacing-genuinely-fails)
as having only two encounters — congiuntivo presente and connettivi
argomentativi, both introduced at U12. For those, the only return point is
Milestone 2, and the carry-forward entry says so plainly rather than pointing at
a lesson that does not exist.

### Escalation

| Trigger | Action |
| --- | --- |
| **One fail** | Carry-forward entry. Continue. |
| **Two consecutive fails** | Carry-forward entries, continue, **and** the learner does the repair set for the earlier of the two structures before the next unit's L2. Repair sets are ~45 minutes of self-study, one per heavy structure, and are **Lesson Designer** deliverables — specified here as a trigger, not built here. |
| **Three consecutive fails, or four in six units** | Stop adding units. Re-run the [placement check](placement-check.md) Parts B, C and E in a parallel version. This is the case format brief §3 anticipates: the learner entered weaker than "solid A2", and the honest response is to change the plan rather than continue collecting fails. |

### The Unit 12 exception, and why it is not a softening

At U12 the congiuntivo is a **first look** (map §5). Testing it unsupported
would be a **construct validity** failure: the item would measure B2. So at U12
only:

- Part B's four main-structure gaps **supply the trigger and the infinitive**,
  and ask for the form. The learner supplies morphology, not the decision to
  subordinate.
- Part D's floor is met by **supported** production: the prompt supplies the
  opinion frames as a stated resource, in the way a phrasebox does.
- TS at U12 is scored against supported production. A learner who produces
  unsupported congiuntivo correctly scores 5; a learner who uses the supplied
  frames correctly scores 3–4 and **passes**. The rubric band meanings are
  unchanged; what changes is the elicitation condition, and it changes because
  the construct changed.

The same logic caps `ci` pronominale (U11 secondary): it is credited wherever it
appears and is never the target of an objective item, because it cannot be
forced without cueing it.

## Worked instantiation — Unit 6

One filled example, so the template is demonstrably buildable. Italian is
specified, not written: every `⟨…⟩` is an instruction to the Italian Content
Editor.

**Unit 6 — A tavola. Checkpoint, L5, 10 minutes, 25 marks.**

### Part A — Receptive (3 min, 4 marks)

- **Stimulus:** ⟨script-read market exchange, 50–60 sec, two speakers: a customer buying three items in different quantities and asking what is good today. Uses `ne`, direct pronouns and at least two participle agreements. Lexis: Set 6 subgroups A and B only. Pace: brisk, falling terminals — the register the culture note describes.⟩
- **A.1** *(gist)* — What is the customer's main purpose? 3 options. ⟨key: they are shopping for a specific dish; distractors both plausible and each contradicted by one clause⟩
- **A.2** *(detail)* — How much of the second item do they buy? ⟨short answer, quantity + container from Set 6 subgroup B⟩
- **A.3** *(detail)* — What does the vendor recommend, and why? ⟨short answer in English⟩
- **A.4** *(main-structure parsing)* — Of two items mentioned, which did the customer **already** buy elsewhere? ⟨answerable only by parsing `l'ho già presa` vs `la prendo`; both items must be named in both turns so keyword matching fails⟩

### Part B — Grammar in context (3 min, 6 marks)

- **Stimulus:** ⟨80-word message from someone reporting back on their shopping: what they bought, what they could not find, what they are cooking. Present and past mixed.⟩
- **B.1–B.4** *(main: pronomi diretti + `ne` + agreement)* — gaps requiring, in this order: a direct object pronoun for a feminine singular noun named in the previous clause; `ne` + a quantity; a direct pronoun in the passato prossimo **with agreement**; a choice between a direct pronoun and `ne` where only one is possible. ⟨alternatives list per gap; agreement is part of the key on B.3⟩
- **B.5–B.6** *(recycled: passato prossimo with participle agreement, from U2)* — two gaps requiring auxiliary choice, one of which takes `essere` with subject agreement.

### Part C — Lexis in context (2 min, 5 marks)

- **C.1–C.3** *(collocation completion, Set 6 subgroup A)* — ⟨three market-transaction phrases with the collocate missing; each gap has a single natural completion plus a stated alternatives list⟩
- **C.4** *(chunk, subgroup B)* — ⟨a quantity-plus-container chunk⟩
- **C.5** *(false friend)* — ⟨the Set 6 false-friend item, in a sentence where the English-interference reading is plainly wrong; one word answer plus a one-word English gloss⟩

### Part D — Productive turn (2 min, 10 marks)

- **Prompt (English):** "You are at a market stall. Buy three things — one by weight, one by number, one by container. Ask the vendor about one of them. Say what you are cooking." Required elements: three purchases in three different quantity types · one question · the dish named.
- **Mode:** spoken, 45–60 seconds, recorded, against ⟨scripted vendor audio with two turns and one pause for the learner⟩.
- **Elicitation floor:** 4 direct-pronoun or `ne` substitutions.
- **TS target:** pronomi diretti + `ne`, with participle agreement where the past is used.
- **Scales:** TA ×1 + TS ×1.

### Pass line for this checkpoint

≥ 18 / 25, **and** TA ≥ 3, **and** TS ≥ 3, **and** ≥ 1 / 2 on B.5–B.6.

## Marking guidance — the rules a marker needs and does not have to invent

1. **Mark the part, not the learner.** Part A is comprehension. If a learner
   writes their Part A short answer in broken English, it is correct if it
   identifies the right content. Nothing in Part A or C is marked for Italian
   accuracy unless the Italian *is* the key.
2. **Do not double-count** ([`rubrics.md` §two rules](rubrics.md#two-rules-that-protect-construct-validity)).
   In Part D, errors in the unit's main structure go to TS. Everything else goes
   nowhere, because GA is not scored at this length. A marker who lowers TA
   because the Italian was rough has turned a task-achievement scale into an
   accuracy scale.
3. **All-or-nothing on objective gaps.** Half marks make 25-mark totals
   incomparable between markers within two units.
4. **Use the alternatives list.** If a learner's answer is not on the list but is
   defensible, mark it correct **and add it to the list** — the instrument is
   used twelve times and improves by being used. Log the addition next to the
   item.
5. **Spelling, accents, double consonants, `Lei` capitalisation:** as
   [`rubrics.md` §Spelling](rubrics.md#spelling-accents-and-tolerance). Not
   marked in A, B or C except where the accent distinguishes the target form.
6. **Avoidance is a result.** A Part D answer that completes the task while
   dodging the target structure scores well on TA and 2 or less on TS, and fails
   the checkpoint on condition 3. That is the intended behaviour, and the
   learner's feedback says exactly that: *the task was done; the structure it
   was built for was not used.*
7. **Report a profile, not a number.** Every checkpoint result is reported as
   four figures — A / B(main) + B(recycled) / C / D(TA,TS) — plus pass or fail.
   A bare "19/25" tells the learner nothing they can act on, and the carry-forward
   list cannot be written from it.

## Construct-validity review checklist

Run on each of the twelve instantiations before it reaches a learner.

- [ ] Part A uses no lexis from later units and no lexis outside this unit's set and earlier ones.
- [ ] Part A item 4 is genuinely unanswerable without parsing the main structure, and cannot be reached by keyword matching.
- [ ] No Part A or C item requires the learner to produce accurate Italian to score.
- [ ] Part B's six gaps split 4 main / 2 recycled, and the recycled structure is a **bolded** entry in this unit's `L4` contract.
- [ ] Every Part B gap has an alternatives list, and no gap is answerable without reading the co-text.
- [ ] Part C has at most one false-friend item and at least one chunk.
- [ ] Part D's prompt lists its required elements and **does not name the target structure**.
- [ ] Part D's elicitation floor is achievable within 45–60 seconds or 40–60 words. A floor a learner cannot physically reach in the time is a floor that fails everyone.
- [ ] Every item traces to a can-do statement for this unit in the syllabus map.
- [ ] Nothing tests a structure introduced later than this unit — checked against `grammar-progression.md`.
- [ ] Before U12: no congiuntivo item anywhere, including in Part A's stimulus as a comprehension target. Seeded chunks may appear in the text; they may not be tested.
- [ ] The ten minutes actually sum: 3 + 3 + 2 + 2, verified by timing the worked answer.
